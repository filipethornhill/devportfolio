Project Summary

"Special Cakes For All Occasions" is a TAFE project showcasing a simulated bakery website. Its goal is to present a variety of cakes available for purchase, with four primary pages: home, cakes for sale, about us, and contact us. The website incorporates CSS grids, HTML forms, a Google Maps iframe, web banners, responsive design, page indicators, and HTML tables to enhance user experience and visual appeal.

Features and functionalities

    CSS Grids

  • Utilized for creating visually appealing layouts and organizing the display of cakes for sale.

    • HTML Forms

  • Implemented to enable user interaction, such as placing orders or making inquiries about specific cakes.

    • Google Maps iframe

  • Integrated to provide location information for the bakery, enhancing accessibility.

    • Responsive Design

  • Implemented to ensure the website adapts seamlessly to different devices and screen sizes, providing an optimal user experience.

Technologies used

CSS (Cascading Style Sheets)

Utilized for styling and layout purposes, including the implementation of CSS grids for organizing the display of cakes and creating visually appealing designs.

HTML (Hypertext Markup Language)

Used as the foundational markup language for building the structure and content of the website, including the creation of HTML forms for user interaction.

Browserling

Used as a testing tool to ensure cross-browser compatibility and verify that the website functions as intended across different web browsers.

webaccessibility

Employed to evaluate the accessibility of the website and ensure it meets web accessibility standards, allowing users with disabilities to access and navigate the site effectively.

observatory mozilla

Utilized to assess and improve the website's security and overall web security best practices, ensuring a secure browsing experience for users.

Visual Studio Code

Used as the primary integrated development environment (IDE) for coding, editing, and managing the project's HTML and CSS files, providing a powerful and efficient development environment.

Challenges and solutions

Designing a Responsive Product Showcase

One challenge I encountered with the product showcases was ensuring a design that looks appealing on any screen size. The solution I discovered was utilizing CSS Grids, which enabled me to effortlessly rearrange the product showcase for different screen sizes. CSS Grids prove to be a valuable tool for managing complex layouts on a website.

Social Media Icons

Implementing responsive and visually appealing social media icons became a challenge, and I quickly realised that using images from a simple Google search was not going to yield satisfactory results. As a result of this, I started doing some research and came across Font Awesome. This allowed me to implement responsive and well-designed social media icons.
